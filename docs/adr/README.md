# Architecture Decision Records (ADR)

One file per decision, numbered `NNNN-slug.md`. These record decisions that are
already fixed in `CLAUDE.md` ("Architecture", "Hard rules") and the specs under
`docs/specs/`; an ADR is the *why* and the alternatives, not a re-statement of
the rule. Changing an "Architecture" or "Hard rule" decision needs the human
(see CLAUDE.md "Working agreements") and a new ADR that supersedes the old one.

Status values: `Proposed`, `Accepted`, `Superseded by ADR-XXXX`.

Template: copy `0000-template.md`.
