# AVP-025 Full-flow and access-control API tests (T-E2E-01, T-SEC-01, T-SESSION-01)

## Goal
A new pytest file that drives the whole API flow in-process with fakes (no network, no DB, no keys) and checks that every session-owned route denies a wrong guest token.

## Context
Files to read first (do not modify them):
- apps/api/tests/test_debrief_api.py  (DebriefHarness, _interview; the harness to reuse)
- apps/api/tests/test_evaluation_api.py  (Harness, Fake* repos)
- apps/api/tests/test_pdf_export.py  (how the PDF route is called)
- apps/api/avp_api/routers/vitals.py  (get_session_repo dependency)

## Allowed paths
- apps/api/tests/test_e2e_flow.py
- .agy/reports/AVP-025.md

## Requirements
Do NOT run any shell command (no pytest, no git): headless mode denies them and the run fails. Only read files and write the two allowed files; the wrapper runs the acceptance command itself.
Create `apps/api/tests/test_e2e_flow.py`. Import `DebriefHarness` from `tests.test_debrief_api` and `FakeSessionRepo` from `tests.test_evaluation_api`. In a helper, also override `avp_api.routers.vitals.get_session_repo` with `lambda: FakeSessionRepo(h.store)` on `h.client.app.dependency_overrides`. All transcripts are synthetic Vietnamese questions.
1. `test_full_flow_session_to_pdf`: POST /api/v1/sessions {"consent": true} -> 201; POST 3 turns -> 200 each; POST /actions {"action":"examine_region","region":"mouth_throat"} -> 200; GET /vitals -> 200; POST /finish -> 200; GET /evaluation -> 200 status "done"; GET /debrief -> 200 status "done"; GET /debrief/pdf -> 200, content-type application/pdf, body starts with b"%PDF-".
2. `test_transcript_persisted_in_order` (T-SESSION-01): after 3 turns, GET /turns returns the student texts in the order sent, with strictly increasing turn idx values.
3. `test_wrong_token_denied_on_every_session_route` (T-SEC-01): parametrize over (method, path, json) for: GET /sessions/{id}, GET+POST /turns, POST /actions, GET /vitals, POST /vitals/events {"event":"TIME_TICK"}, POST /finish, GET /evaluation, POST /evaluation/retry, GET /debrief, GET /debrief/pdf. With header X-Guest-Token "wrong-token" and with no header, the status must be 404 (or 403 / 401). Also a second valid session's token must not open the first session.
4. `test_finish_twice_creates_one_evaluation_chain`: finishing twice still gives exactly one evaluate job and one debrief job.
If an assertion fails because the API behaves differently from this brief, do NOT change application code: mark that one test with `pytest.mark.xfail(reason="...", strict=True)` and describe it in the report.

## Acceptance command
`cd apps/api && python -m pytest -q`

## Out of scope
- Do not edit anything under apps/api/avp_api/, other tests, data/, schemas/, docs/, or prompts.
- No real providers, network, database or .env reads. No clinical text beyond ordinary interview questions.
